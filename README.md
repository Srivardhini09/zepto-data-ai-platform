# Zepto Data & AI Platform

A modular data and AI platform project built using Python, SQL, Machine Learning, and Generative AI concepts.

## Project Overview

This project is divided into three major modules:

1. **Data Pipeline** – Web scraping, data cleaning, SQLite database creation, and SQL analysis.
2. **Analytics** – Titanic dataset analysis, visualization, machine learning classification, and regression.
3. **Support Assistant** – Retrieval-Augmented Generation (RAG) based customer support assistant using policy documents.
